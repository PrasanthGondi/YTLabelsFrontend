How to Get Your Free API Key

  1. Go to the Google AI Studio and sign in with your Google account.
  2. Click on "Get API Key" and then "Create API Key".
  3. Click on "Create API Key in the new project".
  4. Copy the generated API key, paste it above and save it. You can now access AI analysis on YouTube. Open a YouTube video and you should see the analysis in a few seconds.
  5. If you have a GCP account, create a paid plan API to increase your analysis limits.

Features

  • The Basic Plan offers full video analysis on the YouTube video page. The analysis includes an accurate title, summary, labels, thumbnail analysis, fact-checks, and relevant search queries and similar videos with better rank ( Ranked Videos ). Explanations are provided for each label and fact-check. The analysis is done in real-time and is available for all videos with transcripts on YouTube. Currently, English is the only supported language. The analysis is powered by the Google Gemini API.
  • Accurate title and the Label with thumbnail-analysis are available for every video on the subscriptions page as you scroll and on the search page for the top 5 results.
  • The extension automatically adapts to your YouTube light/dark theme.
  • If you think the analysis is incorrect, you can request a re-analysis by clicking on the "Request Reanalysis" button.

Thumbnail Analysis

Thumbnail analysis is available for all videos and includes two labels:

  • Clickbait Detection: This label indicates whether the thumbnail is considered clickbait. A thumbnail will be flagged as clickbait if it doesn't match the video's content.
  • Manipulation Detection: This label determines if the thumbnail has been edited, manipulated, AI-generated, or is misleading. A thumbnail will receive this label if it has been altered or shows no correlation to the video's content.

The analysis is based on comparing the image and video content to ensure accuracy.

Limits

  • The Basic Plan allows analysis of up to 7 new videos per minute and 750+ new videos per day. There is no limit on pre-analyzed videos from the database or local cache. If you need to increase these limits, you can use the paid API from Google Cloud or wait for the Pro Plan.
  • Videos that are up to 2 hours long can be analyzed. Videos longer than 2 hours may not be analyzed, depending on the speed and volume of speech in the video.
  • Analysis happens automatically, so please be aware of the limits. If you exceed the limit, you will need to wait for a minute before continuing with the next analysis.
  • The extension may not perform well with the latest and breaking news, possibly marking them as clickbait or misleading. Please disregard these results on the newest videos. We are working to fix this issue soon.
